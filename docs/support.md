### Frequently Asked Questions (FAQ)

**Q: How do I install Cloud Editor?**
A: You can install Cloud Editor directly from the Google Workspace Marketplace. Once installed, you can right-click any supported file in Google Drive and select "Open with > Cloud Editor."

**Q: Is Cloud Editor free?**
A: Yes, Cloud Editor is provided under the Apache 2.0 License.

**Q: How do I report a bug?**
A: Please email us at the address above with a description of the issue, screenshots (if applicable), and steps to reproduce the error.
